The database holds only Telegram file_id references. On download, the bot re-sends the file using the stored ID.

Run the bot

  1. Clone the repository.

    git clone https://github.com/Yashwanth-Kumar-26/telefile-go.git
cd telefile-go

  2. Create PostgreSQL tables using the included schema.

    psql "$DATABASE_URL" -f setup_db.sql
# or: migrate -path ./migrations -database "$DATABASE_URL" up

  3. Copy the environment template and fill in both Telegram bot tokens, the database URL, and admin IDs.

    cp .env.EXAMPLE .env

  4. Build and start the Go service.

    go build -o telefile ./cmd/telefile
./telefile

Webhook mode is optional. If WEBHOOK_URL is set, register it with Telegram using the secret token from your environment.
